# 나이아 알림 청소

트릭컬 나이아가 화면 위에서 알림을 청소해 주는 Android 앱입니다.

- 앱을 열면 나이아가 물웅덩이에서 빼꼼 나와 튀어나옵니다.
- 평소에는 서 있다가 화면 안을 걸어 다닙니다. 방해 금지 모드에서는 꾸벅꾸벅 좁니다.
- 알림이 오면 인사하며 앱 아이콘과 내용을 말풍선으로 보여 줍니다.
- 알림을 하나 밀어 지우면 물총으로 쏘고, 모두 지우기를 하면 파도를 불러 쓸어 버립니다.
- 톡 = 간지럼, 꾹 눌러 끌기 = 볼 당겨 옮기기, 두 번 톡 = 메뉴(설정·돌려보내기).

필요한 권한: 알림 접근, 접근성(화면 위에 나이아와 효과를 그리기 위해 사용하며 화면 내용은 읽지 않습니다).
